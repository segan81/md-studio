# ADR-0002: Selección de Lit

- Estado: Aprobado
- Fecha: 2026-08-07

---

# Contexto

La interfaz de MD Studio debe ejecutarse dentro de una extensión Chromium.

Se requiere una solución ligera, moderna y basada en estándares Web.

---

# Problema

Frameworks tradicionales como React, Angular o Vue incorporan una capa adicional de complejidad y tamaño que no aporta beneficios significativos para el alcance del proyecto.

---

# Decisión

Se adopta Lit como biblioteca para construir la interfaz de usuario.

---

# Justificación

- Web Components nativos.
- Excelente integración con Chromium.
- Bajo consumo de recursos.
- Excelente soporte para TypeScript.
- Arquitectura basada en componentes.
- Fácil mantenimiento.

---

# Alternativas

## React

Descartado.

Mayor tamaño.

Dependencia del Virtual DOM.

---

## Vue

Descartado.

Mayor complejidad para una extensión.

---

## Angular

Descartado.

Sobredimensionado para el proyecto.

---

## Vanilla TypeScript

Descartado.

Escala pobremente conforme aumenta el número de componentes.

---

# Consecuencias

Positivas

- Código limpio.
- Componentes reutilizables.
- Bajo acoplamiento.

Negativas

- Comunidad menor respecto a React.
