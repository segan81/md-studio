# Product Vision

<!-- MARK: PRODUCT-VISION -->

## Visión

MD Studio será una plataforma moderna para visualizar documentación técnica basada en Markdown, con una experiencia rápida, limpia y extensible.

La primera aplicación del proyecto será una extensión para navegadores Chromium.

En el futuro, el mismo motor podrá utilizarse en otras aplicaciones sin modificar su núcleo.

---

# Misión

Construir un visor Markdown profesional con una arquitectura modular que permita evolucionar el proyecto durante muchos años.

# MVP

La primera versión estable deberá permitir:

- Abrir archivos Markdown.
- Renderizar correctamente.
- Navegación mediante TOC.
- Highlight.js.
- Manifest V3.
- Tema claro.
